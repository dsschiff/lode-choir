# Lode Choir Build Charter

Build a beautiful, fast, character-centered 10-15 minute science-fantasy roguelite
about operating a living mining citadel on a singing moon.

## Player promise

Every shift asks whom to risk, which room to empower, and whether the next route is
worth the damage. The crew remember those choices. The citadel visibly grows. A run
ends with a consequential decision about the Heart-Lode.

## Continuous-build rule

The first complete green run is the floor. Until the session ends, repeatedly pick
the highest-leverage weakness in speed, usability, graphics, sound, imagery, story,
or systems; build it end-to-end; test it; and commit it. Never stop for a reversible
creative decision: choose the most coherent default and record it in the parking lot.

## Definition of done

- Complete seven-shift loop with three endings and explicit losses.
- Four named crew whose strain, loyalty, vows, and scars affect play and epilogues.
- Meaningful room construction/adjacency and route risk.
- Deterministic replay, exact saves, simulations, phone/desktop browser tests.
- A runnable production build with screenshots and honest known limitations.
