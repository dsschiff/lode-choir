# Parking Lot

Reversible decisions recorded during autonomous development. These do not block work.

- **Working title:** Lode Choir. Keep until a later naming/trademark review.
- **Character mortality:** crew gain scars and temporary incapacitation, not permanent
  death, until playtesting shows death would deepen rather than erase attachment.
- **Renderer:** React DOM/CSS/SVG for the vertical slice. Pixi remains a future option
  only if a spatial surface clearly earns it.
- **Publishing:** local repository and production build only; no remote or deployment
  without explicit authorization.
- **Echo Shards:** retain the migrated counter internally, but keep it out of the visible
  Chronicle until it buys a real choice. Scores and run records carry replay value now.
- **Expedition scale:** the vertical slice uses three chamber operators plus one
  optional route leader. Larger away teams, equipment loadouts, and tactical route maps
  remain post-playtest expansions rather than prerequisites for the first run.
